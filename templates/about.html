CampusAI – AI Student Assistance Chatbot

Project Code: P08  |  Reference: Smart India Hackathon (SIH 2024 – SIH1631)  |  Specialization: B.Tech CSE (AI & ML)

🏗️ Technical Architecture & Pipeline

1. Document Extraction: Processes PDF (via pypdf), DOCX (via python-docx), TXT, CSV, and JSON into clean text streams.

2. Semantic Chunking: Recursively splits text into 800-character chunks with 120-character overlap to preserve semantic continuity across sentences.

3. Dense Vector Embeddings: Generates 384-dimensional dense vectors using sentence-transformers/all-MiniLM-L6-v2.

4. Vector Database Storage: Stores vectors and chunk metadata inside a persistent ChromaDB collection indexed with Hierarchical Navigable Small World (HNSW) graphs.

5. Semantic Similarity Search: Computes Cosine Distance between student query embedding and document chunk embeddings.

6. Zero-Hallucination Guardrail: Enforces a distance threshold (0.55). If retrieved passages exceed this distance, the query is safely classified as unverified.

💡 Top Viva Questions & Model Answers

1. Why use RAG instead of simply fine-tuning an LLM?

Fine-tuning updates model weights, which is computationally expensive, slow to retrain when rules change, and prone to hallucinations. RAG decouples knowledge storage from generation: university policies can be updated instantaneously by uploading a PDF, with 100% verifiable source citations.

2. What embedding model is used and why?

We use all-MiniLM-L6-v2 from SentenceTransformers. It maps sentences into a 384-dimensional dense vector space with an exceptional balance between retrieval latency (under 50ms) and semantic precision.

3. Why ChromaDB as the vector database?

ChromaDB is lightweight, embeddable, and runs natively in Python with zero external server infrastructure. It uses persistent SQLite and HNSW graph indexing, making it ideal for university lab setups.

4. How does the system handle ungrounded or fabricated queries?

The pipeline checks cosine distance against a calibrated threshold (0.55). Queries about non-existent campus services (e.g., Martian coins or dinosaur grooming) are identified and intercepted by the guardrail with an official disclaimer.
